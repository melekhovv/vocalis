# Импорт моделей RVC

Единый каталог содержит метаданные русскоязычной подборки и результаты поиска Hugging Face. Веса и аудиозаписи в установщик не входят: выбранные модели скачиваются отдельно из источника. Обязательное ограничение CC0 снято решением владельца; конкретные условия автора показаны в карточке.

1. Подготовьте свою модель RVC v1/v2 для инференса (`.pth`) и соответствующий необязательный `.index`.
2. Откройте «Менеджер моделей → Импорт модели», укажите название, файлы и категорию.
3. Нажмите «Импортировать». Приложение проверяет веса через `torch.load(weights_only=True)` и копирует их в локальное хранилище.
4. В библиотеке остановите живое преобразование и нажмите ▶ на карточке голоса. Windows локально синтезирует фиксированную русскую фразу установленным системным голосом, затем RVC преобразует её выбранной моделью. Свой WAV и микрофон не нужны. Нужны готовые базовые модели и русский системный голос Windows (параметры речи Windows).

Исходник системной речи генерируется один раз за сеанс движка и хранится только локально в `%LOCALAPPDATA%\Vocalis\previews`; после перезапуска он создаётся заново, в том числе после смены системных голосов. Ключ исходника зависит от текста и версии генератора. Преобразованный пример создаётся заново при каждом прослушивании с персональными настройками выбранной модели или её базовыми значениями, если персональных нет. Синтетическая речь помогает сравнить тембр, но не предсказывает качество преобразования вашего микрофона: входная речь и режим обработки отличаются. Готовые сторонние записи и веса для примеров не поставляются.

Локальный синтез использует [System.Speech SpeechSynthesizer](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer?view=netframework-4.8.1), без облачного TTS.

Длинные пути отображаются с многоточием; нажатие на поле открывает выбор другого файла. Полный путь виден при наведении.

Чекпойнты обучения `G_*.pth` и `D_*.pth` не подходят. Расширение `.pth` само по себе не гарантирует совместимость. Используйте стандартные RVC v1/v2 с ContentVec и поддерживаемой архитектурой, а не произвольный файл другой нейросети.

Проверка целостности пересчитывает SHA-256 и повторно проверяет совместимость. Удаление модели доступно в менеджере; активную модель сначала нужно остановить.

Модели и записи пользователя хранятся локально в `%LOCALAPPDATA%\Vocalis`. Они не добавляются в Git или GitHub Release.

Требования к будущим голосам общего каталога: [MODEL_POLICY.md](../MODEL_POLICY.md). Отсутствие лицензии не даёт права на распространение. Собственные модели проверяет их владелец.

## Настройка под свой голос

RVC преобразует звучание речи, а не распознаёт текст. Похожесть тембра, разборчивость и прерывания требуют разных проверок. Рекомендации автора модели — отправная точка: одинаковый сдвиг высоты не подходит любому человеку. Другой каталог не устраняет ошибки переноса настроек или нехватку вычислительной мощности.

Параметры тональности, индекса, защиты согласных, метода F0, чёткой речи и огибающей запоминаются отдельно для каждой модели. При возврате к модели они восстанавливаются; отсутствующие рекомендации не наследуются от предыдущего голоса. Без `.index` его влияние равно нулю. Устройства, чувствительность микрофона, громкость, режим производительности и CPU/GPU остаются общими. Кнопка сброса возвращает базовые настройки только выбранного голоса.

Для первичной настройки включите прослушивание в наушниках и произносите одну и ту же короткую фразу. Изменяйте один параметр за раз:

- Если тембр не похож, подберите тональность под свой диапазон и сравните несколько значений влияния индекса, если есть соответствующий этой модели `.index`. Максимальное влияние не гарантирует лучший результат.
- Если портятся согласные, сравните режим «Чёткая речь» и защиту согласных. Чёткая речь применяется поверх сохранённых значений; её отключение возвращает персональную настройку.
- Если звук прерывается, сначала проверьте показатель нагрузки и выбранное устройство вычислений в разделе системы. Настройки тембра не компенсируют обработку медленнее поступления аудио. Сравните режимы производительности; результаты на CPU и GPU требуют проверки на конкретном компьютере.

Связь индекса с переносом тембра описана в [официальном FAQ RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/faq_en.md). Чужой или некачественный индекс может ухудшить результат; автоматически подтвердить происхождение и соответствие записей весам приложение не может.
