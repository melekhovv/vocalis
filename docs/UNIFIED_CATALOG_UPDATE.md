# Единый каталог 0.2.4 — изменение от 3 ноября 2026

Владелец явно разрешил отказаться от CC0-only и потребовал один каталог, без
отдельного раздела моделей с подтверждённым разрешением. Решение зафиксировано
в MODEL_POLICY.md. Условия источников не отменяются и не объявляются проверенными.

## Поведение

- Один экран и общий список: русскоязычная подборка и поиск Hugging Face.
- Четыре начальных записи: Maizenberg, Nyamura, GLAD VALAKAS, Ivona Maxim.
  Это закреплённые метаданные реальных файлов, не включённые в установщик веса.
- Русские записи показываются первыми по языковым сведениям; неизвестный язык
  не превращается в подтверждённый по названию персонажа.
- CC0 больше не является условием установки. Заявленная лицензия, неизвестные
  права и известные ограничения остаются в карточке.
- Сервер разрешает файлы Hugging Face по immutable revision, путям, размерам и
  SHA-256. Клиент не задаёт адреса скачивания, хеши или разрешения.
- Если метаданные поиска неполные, действие «Проверить файлы» открывает детали.
  В репозитории с несколькими моделями выбираются конкретные веса и индекс либо
  архив. Разные выбранные комплекты имеют независимые ID и не подменяют друг друга.
- Нет повторного лицензионного checkbox для каждого скачивания. Технические
  проверки HTTPS, архивов, весов, FAISS и атомарной установки сохранены.

Внутренний provider ID `approved` оставлен для совместимости сохранённых данных;
его пользовательское имя — подборка, а не подтверждение прав. Другие сайты без
подтверждённого API не выдаются за подключённые автоматические провайдеры.
Сейчас подборка содержит разных авторов, файлы размещены на Hugging Face.

## Проверки

Реальная установка Nyamura через динамический Hugging Face-провайдер прошла:
86514507 байт, совпали хеши весов и индекса, проверены RVC v1/40 kHz/F0 и FAISS,
модель зарегистрирована и доступна через voice_paths. Тест использовал изолированное
временное хранилище; скачанные веса после проверки удалены. Микрофон и инференс
не запускались. Обнаруженная на реальном файле совместимость старых имён
weight_g/weight_v учтена без отключения проверки форм тензоров. Неоднозначные
смешанные представления отклоняются.

Финальные typecheck, renderer/Electron build и 8 групп UI-регрессий прошли.
Интерфейс осмотрен при 1280×800 и 1040×600. Проверены загрузки без CC0, выбор
нескольких моделей одного репозитория, отдельные прогресс/отмена/использование,
избранное и работа с сохранёнными метаданными. Между быстрым поиском и открытием
деталей частота сетевых запросов ограничивается ожиданием в worker, а не ошибкой
основного пользовательского действия.

Независимые сценарии: [UNIFIED_CATALOG_TESTING.md](UNIFIED_CATALOG_TESTING.md).
Звучание микрофона, GPU и Discord проверяется отдельно от загрузки и структурной
совместимости весов. Пользовательские модели и записи не используются в тестах.

единого каталога и прежние 7 security-тестов. Lifecycle и mock-установка кабеля:
