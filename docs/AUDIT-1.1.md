# Аудит Vocalis 1.1

Проверены приложение Electron/React, Python-аудиодвижок, сохранение настроек, установка и состав Windows-пакета. Работа разделена между профилями app_developer, audio_engineer и release_engineer из .codex/agents; выполнена перекрёстная проверка изменений.

## Исправления

- Повторный запуск во время установки мог открыть неполное Python-окружение. Установка теперь отслеживается, параллельный запуск блокируется, процесс установки завершается при выходе.
- Выход мог бесконечно ждать ответа движка: добавлен таймаут.
- Некорректные сохранённые настройки могли ломать интерфейс и аудиопараметры. Восстанавливаются только значения допустимого типа и диапазона; неизвестные поля не применяются.
- Выбор устройства с индексом 0 ошибочно заменялся устройством по умолчанию.
- Ошибка открытия аудиовыхода оставляла микрофон занятым. Частично открытые потоки освобождаются.
- Остановка во время прогрева могла позже включить микрофон, а повторный запуск — конфликтовать с ещё работающим потоком. Добавлены проверка отмены и безопасное завершение обработки.
- Очистка аудиобуфера не сбрасывала состояние первоначального заполнения.
- Старое WebSocket-соединение могло сбросить состояние нового; устаревшие показатели после отключения сохранялись на экране.
- Переключение на предыдущий голос без текущего выбора пропускало последний голос.
- Некоторые ошибки операций не показывались пользователю; добавлены уведомления.
- Скрипты подготовки могли сообщать успех после ошибки uv, импорта torch или отсутствия Electron.
- После сборки с --publish never могли оставаться старые latest.yml и SHA256SUMS.txt. Метаданные теперь формируются из готового установщика текущей версии.
- Обещанные уведомления о лицензиях не попадали в пакет; добавлены в resources/licenses. Описание комплектации уточнено в THIRD_PARTY_LICENSES.md.

## Что остаётся за границами выпуска

Нет встроенного установщика виртуального аудиодрайвера; VB-CABLE ставится отдельно. Нет ускорения AMD/Intel через DirectML или ROCm. Весовые файлы голосов поставляются отдельно от установщика. Цифровая подпись установщика и автоматическое обновление не заявляются.

Автотесты и снимки интерфейса не подтверждают качество длительного звонка, сквозную задержку, стабильность всех драйверов и всех видеокарт. Discord, физический микрофон и GPU под длительной нагрузкой в этом аудите не тестировались. Не заявляется отсутствие любых возможных багов.

## Воспроизвести проверки

- `npm --prefix app run typecheck`
- `node app/tests/startup.cjs`
- `node app/tests/settings.cjs`
- `engine/.venv/Scripts/python.exe -m unittest discover -s engine/tests -p "test_*.py"`
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1`

Снимки сделаны штатным VOCALIS_SHOTS без записи микрофона, с отдельными настройками Electron и установленными на компьютере моделями. Пользовательские модели и настройки не входят в Git и установщик.

## Результаты

36 тестов Python прошли, включая перестановки ключей настроек и конкурентное открытие/закрытие аудиопотоков. TypeScript, startup.cjs и settings.cjs прошли. Скрипты PowerShell проверены парсером; на временных фикстурах подтверждены корректный отказ после uv/import ошибки и успешный сценарий установки. Проверка diff не обнаружила ошибок форматирования.

Windows-установщик 1.1.0 собран успешно. В unpacked-пакете подтверждены версии app/engine 1.1.0, четыре файла лицензий и 13 штатных demo/preview WAV; пользовательские данные и инструкции команды отсутствуют. Проверен запуск packaged-приложения с установленным runtime: интерфейс подключается к движку и открывает страницы; актуальные снимки этой сборки включены в README. Установка на чистой Windows не выполнялась.
