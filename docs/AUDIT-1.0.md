# Аудит и доработки 1.0

Основание: девять обязательных пунктов «Доработки.md». Обработка звука, веса и параметры заводских моделей от 0.1.5 сохранены.

1. Установка: живой вывод текущего этапа и пакета, обновляемый из stdout/stderr uv. Индикатор неопределённый: общего процента байтов uv в pipe не сообщает; фиктивных процентов нет. Ошибки запуска установщика отображаются.
2. Требования и порядок установки движка, моделей и VB-CABLE описаны в README и на экране первой установки. NVIDIA/CUDA и CPU поддерживаются; ускорение AMD не обещается.
3. Старые логи очищаются после VOCALIS_READY. Неудачный запуск сохраняет диагностику. Исправлены повторный запуск процесса, зависшая ссылка после spawn error и бесконечный цикл ready/crash.
4. Сохранены 12 готовых речевых примеров и фиксированный текст. Микрофон/WAV пользователя не нужен. Общие тесты проверяют ненулевой конечный WAV и работу примера при активном движке.
5. При ручном CPU явно написано «прогрев CPU». При автоматическом выборе не объявляется заранее GPU. Прогрев сохранён: он подготавливает модель к первому аудиоблоку.
6. При запуске показывается тост, если вывод не направлен в виртуальный кабель, с маршрутом настройки. Отсутствующие базовые модели блокируют запуск с уведомлением.
7. Устойчивая перегрузка даёт тост сверху справа. Повтор не чаще раза в минуту; остановленный движок не генерирует предупреждения.
8. Настройки используют обычную прокрутку overflow:auto вместо Radix-полосы; уменьшен лишний нижний отступ. На малом экране необходимая прокрутка сохранена.
9. Недавние обновляются по подтверждённому состоянию движка, включая горячие клавиши и восстановление выбора. Убраны дублирующие записи из UI, дубликаты списка фильтруются.

Дополнительно: пакет параметров валидируется целиком до применения. NaN, Infinity, неизвестные поля/методы, неправильные типы и значения вне диапазона отклоняются с HTTP 400. Защита от частично применённых неверных настроек проверена регрессионными тестами. Проверены существующие механизмы локального токена API, безопасной загрузки checkpoint weights_only, контрольных сумм и выборочного извлечения ZIP.

Проверки: TypeScript, 28 тестов Python, тест жизненного цикла Electron, production-сборка. Снимки интерфейса выполняются с отдельными настройками. Проверка длительного звонка, драйверов на всех Windows и всех AMD/Intel/NVIDIA не выполнена; это не независимая сертификация безопасности. Криптографическая подпись установщика без сертификата не заявляется.

Идеи из отдельного раздела файла (веб-каталог, установка стороннего драйвера внутри установщика, разные пакеты вычислений, персонализация карточек) не входят в девять исправлений и не объявляются реализованными в 1.0.

Модели публикуются отдельным Release-архивом с исходными файлами и проверенными SHA-256, а не гигабайтными Git-объектами. Внутри только 12 заводских профилей; пользовательские голоса и записи исключены.
