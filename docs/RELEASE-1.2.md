# Vocalis 1.2.0

Обновление для Windows x64 с исправлениями стабильности, управлением зависимостями, деинсталлятором и новыми инструментами настройки голоса.

## Что нового

- **Удаление зависимостей:** в «Настройки → Приложение» и «Менеджер моделей» можно посмотреть объём и отдельно удалить Python/PyTorch-окружение, базовые нейросети и кэш загрузок, сохранив свои голосовые модели.
- **Штатный деинсталлятор Windows:** добавлен сценарий удаления `installer.nsh` — автоматически останавливает фоновый движок, убирает запись автозапуска, создаёт ярлык «Удалить Vocalis» в меню «Пуск», предлагает очистить загруженные зависимости и запускается прямо из настроек программы.
- **Тест записи «До / После»:** запишите 4-секундную фразу с микрофона на главном экране и сравните оригинал с обработанным голосом; после изменения ползунков можно сразу пересчитать результат без повторной записи.
- **Профили для каждого голоса:** выбранная тональность, `index_rate`, `protect` и метод F0 теперь запоминаются индивидуально для каждого голоса и при желании сбрасываются одной кнопкой.
- **Диагностика и готовность:** страница «Система» получила чеклист готовности (движок, CUDA/CPU, нейросети, микрофон, VB-CABLE), кнопку копирования журнала и экспорт диагностического отчёта.
- **Исправления ошибок:** устранён сбой при переключении на F0 `crepe` во время работы, исправлена изоляция настроек при смене моделей, добавлена отмена установки движка, обнаружение конфликтующих горячих клавиш и повторная загрузка аватаров после восстановления сети.
