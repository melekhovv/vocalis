# Архитектура

- `app/src/main`: Electron, запуск Python, установка окружения через uv, горячие клавиши и трей.
- `app/src/preload`: ограниченный IPC-мост между оболочкой и интерфейсом.
- `app/src/renderer`: React, TypeScript, Tailwind и Radix/shadcn-компоненты.
- `engine/vcengine`: HTTP/WebSocket API на 127.0.0.1 с токеном запуска, устройства, RVC-конвейер и локальный менеджер моделей.
- `engine/vendor`: адаптированный inference/realtime-код Applio с сохранённой MIT-лицензией.
- `catalog`: источники базовых нейросетей и метаданные русскоязычной подборки; веса скачиваются отдельно и не входят в поставку.
- `engine/vcengine/catalog.py`: единый каталог с подборкой и поиском Hugging Face, кешем и серверным разрешением файлов для загрузки. Правило CC0-only отменено владельцем; метаданные лицензии не являются подтверждением прав. Подробный контракт: [VOICE_CATALOG.md](VOICE_CATALOG.md).
- `engine/vcengine/quality.py`: применимость профилей F0/индекса и поддерживаемые режимы качества; персональные настройки имеют приоритет в допустимых пределах модели.

Аудио: микрофон → блоки по 10 мс → ограниченная очередь → RVC worker → ограниченные выходные FIFO → виртуальный кабель и отдельные наушники. Переключение прослушивания не переоткрывает основной вывод. Отмена загрузки и перезапуск сериализованы, старая нейросеть освобождается перед запуском новой.

Оболочка получает статусы через WebSocket с частотой 10 Гц. Проверка моделей и тяжёлая конвертация выполняются вне цикла HTTP-сервера. Пользовательские веса и записи не передаются в сеть.

Репозиторий не содержит весов, записей, окружений, кэшей и сборок. Инструкции для разработки и сборки: [README](../README.md). Установщик содержит код, uv, зависимости Electron и тексты лицензий; Python/RVC-зависимости и базовые модели ставятся отдельно.
