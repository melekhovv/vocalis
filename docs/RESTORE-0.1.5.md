# Восстановление Vocalis 0.1.5

Дата: 4 ноября 2026, Asia/Sakhalin. Рабочая папка: D:/Vocalis. Локальная ветка: restore/0.1.5-20261104.

## Что сохранено перед восстановлением

D:/Vocalis-backups/before-restore-0.1.5-20261104 содержит полный Git bundle, исходники 0.2.4, прежний установщик и копию настроек движка. Состояние Git до восстановления: 5ac32e5; резервная ветка backup/before-restore-0.1.5-20261104. Файлы установленных моделей и персональные аудионастройки не заменяются.

## Основание восстановления

Оригинальный установщик 0.1.5 не найден. Использованы сохранённая исходная копия проекта, журнал первоначальной разработки и обратимые патчи последующих изменений. Команды из истории целиком не запускались: применялись проверенные блоки изменения конкретных исходников. Поздние код, каталог и проверки 0.2.x исключены из восстановленной сборки.

Интерфейс восстановлен из исходного состояния и оригинальных изменений. Повторная production-сборка дала те же имена с хешами содержимого, что записаны при сборке 0.1.5:

- app/out/renderer/assets/index-pgibRCEZ.js, 1211.07 kB;
- app/out/renderer/assets/index-BKcaSjGX.css, 84.67 kB.

Главный процесс Electron восстановлен из исходной копии с оригинальными изменениями 0.1.5; размер сборки 15.15 kB. Воспроизведение этих результатов не доказывает побайтовую идентичность всего NSIS-установщика, поскольку исходного EXE для сравнения нет.

## Состав

12 русских заводских голосов, 12 сохранённых WAV-примеров и исходный demo-ru.wav. Примеры используют фразу «Привет! Ну что, готов к приключениям? Тогда поехали!» и не обращаются к микрофону. Исходный реестр из восьми источников относится к дате проверки версии 0.1.5; свежая проверка источников не подменяет исторические метаданные.

Возвращены настройки моделей и потоковая обработка 0.1.5, включая корректные mel-границы F0 и optional clarity_mode=false. Включение «Чёткой речи» ограничивает index_rate до 0.4, protect до 0.1; выключение возвращает профиль голоса.

## Проверки

Все 24 исходных теста, TypeScript, проверка lockfile и упаковка завершились успешно. Результаты и контрольные суммы сохранены в [манифесте](restore-0.1.5-manifest.json). Тесты и снимки интерфейса используют отдельную папку данных. Микрофон и пользовательские записи для QA не используются.

Сохранены рабочие PowerShell-обёртки сборки для текущего расположения проекта. В упаковку добавлен только запрет публикации --publish never; логика голосов от этого не меняется. После успешной упаковки в app/release остаётся установщик 0.1.5. Прежний установщик доступен в резервной копии вне этой папки.

## Дополнительная проверка исходников моделей

У четырёх архивов восстановлены недостающие объявления загрузки. Их выбранные pth/index проверены по SHA-256 и побайтно совпали с исходными установленными моделями. Для Hugging Face закреплены ревизии, использованные при этой проверке; для публичного архива Геральта закреплена контрольная сумма ZIP. Это метаданные реконструкции, а не утверждение о полном совпадении исторического JSON. Веса не заменялись.

Проверка реального потокового преобразования готовой фразы прошла на Пудже и Геральте. p95 вычислений: около 138 и 160 ms при блоке 200 ms на этой машине. Это не измерение полной задержки микрофона. Все 12 заводских моделей найдены готовыми; шесть пользовательских моделей сохранены.
