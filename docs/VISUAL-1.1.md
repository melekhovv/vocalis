# Проверка интерфейса 1.1.0 — 2026-11-04

Версия сохранена: 1.1.0. Обновляется установщик существующего выпуска.

## Исправления

- Убрано ограничение ширины страницы «Система», из-за которого в развёрнутом окне справа оставалась пустая половина экрана. Сетки учитывают ширину рабочей области после боковой панели.
- Главный экран прокручивается при нехватке высоты. Длинные названия и подписи индикаторов переносятся, правая панель учитывает ширину окна.
- Статус и задержка внизу боковой панели размещены отдельными строками.
- Категории библиотеки и вкладки настроек переносятся, оставаясь видимыми.
- Карточки режимов производительности выровнены по высоте. Строки менеджера моделей перестраиваются; длинные пути и ошибки не растягивают контейнеры. Диалоги ограничены высотой окна с прокруткой.

## Проверка

TypeScript, существующие startup.cjs/settings.cjs и git diff --check проходят. Сборка Windows x64 выполнена с прежней версией.

Штатный VOCALIS_SHOTS расширен: VOCALIS_SHOTS_SIZE=1040x680, 1280x800, 1920x1080; снимки всех пяти страниц, всех вкладок настроек, источников и импорта. Для импорта возвращается искусственный длинный путь: реальный файл и системный диалог не открываются. Проверяется геометрия элементов относительно границ окна. Анимации отключены только в режиме снимков, чтобы скрытое окно не давало промежуточный кадр.

Снимки и отчёты сохраняются в app/tests/out/ и не публикуют пользовательские модели или настройки. Осмотрены страницы системы, главная, библиотека, настройки и импорт. При минимальной высоте содержимое доступно прокруткой. Проверка геометрии не заменяет проверку читаемости снимков.

Это проверка интерфейса; установка на чистой Windows, работа микрофона и длительный звонок не проверялись.

В отчёте 1920x1080 один progress-indicator выходит за геометрическую границу до обрезания родителем overflow-hidden. На снимке шкала остаётся внутри карточки; это штатное смещение заполнения шкалы, а не видимое переполнение.
