> Исторический отчёт версии 0.2.3. После явного решения владельца правило CC0-only
> отменено для единого каталога. Актуальное изменение: docs/UNIFIED_CATALOG_UPDATE.md.

Дата: 2026-11-03, Asia/Sakhalin. Публикация GitHub не выполняется.

## Существенное ограничение приёмки

Hugging Face Hub предоставляет рабочий публичный API. Проверены десять RVC-кандидатов
с заявленным CC0; достаточные свидетельства CC0 исходных записей не найдены.
Ни одна из этих моделей не добавлена в одобренный каталог. Это ограничение
проверенной выборки, а не доказательство отсутствия подходящих моделей в интернете.
MODEL_POLICY.md и THIRD_PARTY_LICENSES.md не изменены.

Следовательно, сценарий скачивания реального одобренного голоса и проверки его
звучания имеет статус **BLOCKED**. Фикстуры установки не выдаются за готовые голоса.
Поисковая интеграция и установщик проверяются отдельно от наличия одобренного контента.

## Источники и архитектура

Официальный HF API используется только для публичных метаданных. Карточка или тег
лицензии не разрешает установку. Разрешение определяется локальным проверенным
манифестом, закрепляющим права, ревизию и файлы. VoiceModels не интегрирован:
разрешённый официальный API не подтверждён. Подробные URL, даты и результаты
запросов сохранены в docs/VOICE_SOURCES.md.

Аудио остаётся локальным. HTTP/WebSocket сохраняют loopback и токен запуска;
каталог не принимает произвольные URL установки от renderer. Существующие импорт,
локальная библиотека, выбор и удаление используются повторно. Протокол и добавление
провайдеров описаны в docs/VOICE_CATALOG.md.

## Качество

Balanced, HighQuality и LowLatency соответствуют реализованным режимам
balanced, quality и performance. Стартовые параметры учитывают проверенный F0 и
индекс; индивидуальные настройки пользователя сохраняются. Профили являются
технически допустимыми стартовыми значениями, а не результатом прослушивания
каждой удалённой модели. Синтетические тесты буферов не доказывают похожесть тембра
и сквозную задержку микрофон → Discord. Подробнее: docs/AUDIO_QUALITY.md.

## Известные ограничения

- Одобренные записи пока отсутствуют; категории не заполняются фиктивным контентом.
- Поиск возвращает ограниченную выборку до 30 записей на запрос, не весь Hub.
- Удалённые данные могут быть неполными; неизвестные размер, язык и совместимость
  показываются как неизвестные. VoiceModels не интегрирован без подтверждённого API.
- Настройки по умолчанию не являются акустической оптимизацией под конкретного
  человека. Не проводилось прослушивание реальных голосов на CPU/GPU.
- PyTorch/FAISS выполняют разбор внутри процесса, без OS sandbox и отдельного
  лимита памяти процесса. Проверки формата и хешей не являются абсолютной защитой
  от любой ошибки стороннего парсера. Файлы ограничены 2 GiB, ZIP — 3 GiB после
  распаковки, 1024 записи и допустимый коэффициент сжатия.
- Подтверждённая размерность индекса не доказывает его семантическое соответствие
  весам. Пользовательский локальный импорт не становится одобренной записью.

## Последующая публикация

Публикация не выполняется автоматически. После локального тестирования владелец
должен отдельно разрешить публикацию. Чистая папка предназначена для проверки
исходников; перед публикацией следует ещё раз проверить состав, лицензии и
отсутствие пользовательских данных. Наличие установщика не означает разрешение
на публикацию весов или записей.

Порядок последующей подготовки: проверить SOURCE_MANIFEST.json/SHA256SUMS.txt,
выполнить setup и тесты по README/RELEASE, сверить лицензии, затем отдельно получить
решение владельца о публикации. Только после этого можно инициализировать историю
Git в чистой папке, подготовить локальный commit и согласовать удалённый репозиторий
и публикацию. В рамках этой задачи эти удалённые действия не выполнялись.
